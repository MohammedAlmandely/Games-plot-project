# 📌 Games Plot Project 🎮

It is an interactive Q&A platform, similar to Reddit, but dedicated to games and gamers from all over the world.

## 🚀 Key Features
- An integrated platform designed for interaction among players from all over the world.
- A comprehensive control panel for administrators with defined permissions.
- Interactive systems such as likes and a leveling system.
- The ability to attach images and videos, and to select the content type for a question so that it is added to the appropriate category.

## 🛠️ Technologies Used
- **Front-end:** HTML, CSS, JavaScript
- **Database & Hosting:** SQL, Firebase
